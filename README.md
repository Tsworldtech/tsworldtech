## Flux

**Local first infrastructure for web applications.**

Flux helps web applications continue working when internet connectivity is slow, unstable, or temporarily unavailable.

Application data stays available on the device and synchronizes with the backend when connectivity returns.

Flux is designed to work with existing application architectures rather than requiring developers to replace their backend, database, or state management.

### Flux provides

• Local data persistence  
• Offline application support  
• Realtime synchronization  
• Cross tab data coordination  
• Offline writes and synchronization  
• Delta synchronization  
• Conflict handling  
• Multi tenant data isolation  
• Next.js and React integrations  
• Supabase, SSE, WebSocket, and Socket.IO integrations  
• CLI tooling for installation and configuration
